# День 16. Подключение MCP

Минимальный клиент, который подключается к публичному MCP-серверу и
выводит список доступных инструментов (`tools/list`).

Два варианта (ТЗ разрешает оба):

- **удалённый** — публичный сервер DeepWiki по интернету (по умолчанию);
- **локальный** — свой MCP-сервер `local_server.py`, клиент сам его запускает
  и подключается по stdio. Работает без интернета.

Удалённый сервер — **DeepWiki** (`https://mcp.deepwiki.com/mcp`):
публичный, бесплатный, **без ключей и регистрации**. Даёт инструменты
для чтения документации по GitHub-репозиториям.

## Файлы

- `list_tools.py` — основной клиент на официальном **MCP SDK** (`pip install mcp`),
  умеет оба режима: удалённый и `--local`.
- `local_server.py` — минимальный локальный MCP-сервер (`add`, `echo`, `current_time`).
- `list_tools_raw.py` — запасной вариант **без SDK**: тот же протокол руками
  (JSON-RPC поверх HTTP). Полезен, чтобы увидеть, что происходит «под капотом»,
  и если SDK не ставится.
- `run.ps1` — запуск в одну команду.

> Старый адрес `https://mcp.deepwiki.com/sse` DeepWiki отключил (отвечает `410 Gone`).
> Используйте только `/mcp` (Streamable HTTP) — он стоит по умолчанию. Параметр
> `--transport sse` оставлен для других серверов, которые ещё работают по SSE.

## Как работает подключение

1. **initialize** — клиент представляется, сервер отвечает своим именем,
   версией и выбранной версией протокола; обычно выдаёт `Mcp-Session-Id`.
2. **notifications/initialized** — клиент подтверждает, что готов.
3. **tools/list** — сервер возвращает инструменты: имя, описание и
   JSON-схему входных параметров.

## Запуск (PowerShell)

```powershell
cd "путь\до\day16-mcp-connect"
.\run.ps1
```

Если Windows блокирует скрипт:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Другие варианты:

```powershell
.\run.ps1 -Mode local    # свой локальный сервер, без интернета
.\run.ps1 -Mode raw      # DeepWiki без SDK
```

Без `run.ps1`, вручную:

```powershell
python -m pip install -r requirements.txt
python .\list_tools.py
```

## Что должно получиться

```
Подключаюсь к https://mcp.deepwiki.com/mcp (транспорт: http) ...
Соединение установлено ✅
Сервер: <имя сервера> <версия>
Версия протокола MCP: <версия>

Доступно инструментов: N

1. <имя инструмента>
   Описание: ...
   Параметры:
     - repoName: string (обязательный)
...
```

Ожидаемый результат:

- удалённый режим — 3 инструмента DeepWiki: `read_wiki_structure`,
  `read_wiki_contents`, `ask_question`;
- локальный режим — 3 инструмента: `add`, `echo`, `current_time`.

## Проверка ТЗ

| Пункт ТЗ | Где проверяется |
|---|---|
| Установить MCP SDK / клиент (или поднять локальный сервер) | `mcp` ставится в `run.ps1`; локальный сервер — `local_server.py` |
| Установить MCP-соединение | строка `Соединение установлено ✅` + имя сервера и версия протокола |
| Получить список инструментов | блок `Доступно инструментов: N` со списком |
| Соединение устанавливается | при ошибке скрипт пишет `Не удалось подключиться ❌` и причину |
| Список корректно возвращается | у каждого инструмента есть имя, описание и параметры из `inputSchema` |
